# Kalman Filter Study Notes

This repository contains study notes, mathematical derivations, and simulations related to Kalman Filters and state-space models.

## Structure

The project is organized into the following categories:

### [Theory](docs/theory/)
- [Key Kalman Filter Concepts](docs/theory/concepts.md): Introduction to KF, models, and probabilistic inference.
- [Why Understand KF Internals?](docs/theory/why-kf-internals.md): Motivation for deep diving into the mathematics of KF.

### [Models](docs/models/)
- [State-Space Time-Domain Response](docs/models/state-space-time-domain.md): Analysis of continuous-time linear state-space models.
- [Time-Domain Response Illustration](docs/models/time-domain-response-illustration.md): Diagonalization and eigenvalue interpretation.
- [Converting Continuous-Time to Discrete-Time](docs/models/continuous-to-discrete.md): Step-by-step derivation of discretized systems.
- [Observability and Estimation](docs/models/observability-and-estimation.md): Criteria for state estimation.

### [Setup](docs/setup/)
- [Octave Kernel Setup](docs/setup/octave-kernel-setup.md): Instructions for configuring the Octave kernel for Jupyter.

### Code and Simulations
- [code/](code/): Jupyter notebooks and Octave scripts for simulating discrete-time systems.

## Getting Started

To explore the content, you can start with the [Table of Contents](Content.md) or dive directly into the [Core Concepts](docs/theory/concepts.md).

If you want to run the simulations, check the [Octave Kernel Setup](docs/setup/octave-kernel-setup.md).
